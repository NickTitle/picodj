# Pocket Tracker architecture

- [Product requirements](REQUIREMENTS.md) defines cartridge-only PICO-8
  parity, later LSDJ-style scope, constraints, quality bars, and owner choices.
- [Technical design](DESIGN.md) defines the native audio-bank model, UI,
  persistence adapters, browser GPIO boundary, codecs, and tests.
- [M1 Track 1 specification](M1_TRACK_1_SPEC.md) pins canonical Starfield
  provenance and gives staged implementation and acceptance criteria.

The documents describe the target that supersedes the current four-channel,
sixteen-step interaction prototype. The prototype files remain unchanged.
