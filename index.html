Pocket Tracker help

Use the on-screen PICO-8 controls or a keyboard. O confirms and X returns or cancels.

SONG

Up/Down chooses pattern 00–3f. Left/Right chooses a channel. O opens its SFX. Hold X for SFX assignment, mute and flow flags, audition mix, undo/redo, and playback.

SFX

Up/Down moves through 32 rows and Left/Right chooses the field. O edits. Tap X returns to SONG. Hold X for row operations, metadata, filters, preview, undo/redo, and slot navigation. O+X toggles note/rest.

Accelerated input

A D-pad press changes once. Ordinary SONG/SFX movement and staged scalar values repeat after a sustained hold, then accelerate. O/X actions, chords, menus, confirmations, row-range selection, and destructive commands never use accelerated repeat.

Projects and recovery

Hold O in the tracker for browser-slot and data-cart Save/Load. Tracker Save updates only the last-known-good browser slot. The Files panel keeps up to eight projects with four validated saved copies each; new project and revision actions snapshot that slot.

Stage copies a validated revision into the browser slot. Tracker Load is the only action that commits it live. Corrupt newer copies fall back to older valid ones without rewriting storage. Failed, cancelled, quota-limited, or stale actions preserve the library, browser slot, and live tracker. Recovery and library reset never change the browser slot or live tracker.
